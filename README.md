# A股主力资金流向多维监测看板 · Smart Money Flow Dashboard

实时监测：两市成交额、头部宽基 ETF 主力净流入、融资净买入（T+1）、板块资金轮动与量价信号、龙虎榜席位结构，以及四维加权情绪评分。支持 今日 / 近3日 / 近5日 / 近20日 四个周期。

在线地址：https://zsy0216.github.io/smf-dashboard/

## 数据是怎么来的（v2.0 已接入真实数据）

三层架构，全部跑在静态 GitHub Pages 上，不需要任何后端：

1. **浏览器直连（主）**：`index.html` 尾部的加载器直接请求东方财富公开接口
   （`push2` / `push2his` / `datacenter-web`，均开放 CORS），在本地组装数据并渲染。
   交易时段每 **60 秒**自动刷新（日粒度数据有 10 分钟缓存，单次刷新只发约 4 个实时请求，避免触发源站限流；`push2` 被限流时自动改走 `push2delay` 延迟域名）。
2. **快照兜底**：直连失败时自动改读同仓库的 `data.json`，由 GitHub Actions
   （`.github/workflows/update-data.yml`）在交易日 09:00–15:59 每 10 分钟运行
   `scripts/fetch_snapshot.py` 生成并提交，口径与前端直连完全一致。
3. **模拟兜底**：两者都不可用时保留内置演示数据，顶部徽标会明确显示
   「实时数据暂不可用 · 显示模拟数据」，不会冒充真实行情。

顶部徽标实时标注当前数据状态；两融（T+1）与龙虎榜（最近交易日）的截至日期写在各周期 stamp 中。

## 口径要点

- 两市成交额 = 上证指数 + 深证综指成交额（不含北交所）；盘中涨跌幅与**昨日同时段**累计比较，收盘后切换为与昨日全天比较。
- 板块 / ETF「净流入」= 主力净额（超大单 + 大单）；板块表第三列为超大单净额；20 日累计由日频资金流 K 线逐日相加。
- ETF 监测池：510300、159352、159915、512100、588000、510050、159919、512880（可在加载器 `ETF_WATCH` 中改）。
- 融资净买入 = 两融报表 `RZJME`（融资买入 − 融资偿还），T+1 披露。
- 龙虎榜 = 最近交易日席位明细（买/卖两张报表去重合并）聚合为：机构专用 / 沪深股通 / 拉萨系 / 其余营业部（游资合计）。
- 情绪评分 = ETF 资金 30% + 杠杆情绪 20% + 板块轮动广度 25% + 博弈结构 25%，公式在加载器与快照脚本中各有一份实现，保持一致。
