二、如何替换为真实数据（三步）

第 1 步：把本文件的 DATA 常量替换为一次 fetch 结果。所有数值的单位与正负号语义保持不变：净流入为正、净流出为负，金额统一为「亿元」。

第 2 步：新增一个 loadRealData()，把接口返回值映射成同一结构后调用 renderAll()，图表无需改动。

第 3 步：跨域受限时（东方财富接口无 CORS 头），走自建代理或在服务端预取成 JSON，前端只读自有域名的静态文件。

// 板块大单净流入：东方财富 push2（f62 单位＝元）
async function fetchSectorFlow() {
  const url = 'https://push2.eastmoney.com/api/qt/clist/get'
    + '?pn=1&pz=50&po=1&np=1&fltt=2&invt=2'
    + '&fs=m:90+t:2&fields=f12,f14,f2,f3,f62,f184';
  const r = await fetch(url).then(x => x.json());
  return r.data.diff.map(d => ({
    name: d.f14,
    code: d.f12,
    chg: d.f3,
    big: d.f62 / 1e8,          // 元 → 亿元
    margin: 0                   // 融资净买入需另取两融明细后合并
  }));
}

三、信号判定逻辑（页面内自动计算，非人工标注）

  • 高位派发预警 大单净流入 > 0 且 |涨跌幅| < 0.6% 且 量比 ≥ 1.8 —— 巨量滞涨，通常是承接盘在替出货方接单。
  • 主力吸筹 大单净流入 > 0 且 涨跌幅 < 2% —— 资金进场但股价未透支。
  • 主升共振 大单净流入 > 0 且 涨跌幅 ≥ 2% —— 资金与价格同向，趋势最强但需防高位。
  • 拆单暗吸 / 量价背离 大单净流出 < 0 且 涨跌幅 > 0 —— 明面大单流出、股价抗跌，多为算法拆单隐蔽吸筹。
  • 资金撤离 大单净流出 < 0 且 涨跌幅 ≤ 0 —— 价量资金三杀，最弱结构。

四、看盘口诀

  • ETF 是慢钱：连续 3 日净申购而指数横盘＝机构低位收集；单日脉冲多为期现套利，不构成方向。
  • 融资是快钱：融资净买入放大而指数不涨＝杠杆滞涨，是兑现信号而非进攻信号。
  • 板块看连续性：单日资金回正不算信号，连续 2 日净流入且金额递增才有效。
  • 背离看方向：跌不动＋大单流出＝吸筹；涨不动＋巨量大单流入＝派发。
  • 龙虎榜看结构不看个股：机构买、散户卖＝筹码集中；游资接力、机构撤退＝情绪尾声。
  • 四维共振才加仓：ETF 申购＋融资回升＋板块资金转正＋情绪 ≥ 60，缺一即降杠杆。

五、口径与免责

本页所有数值为前端内置的模拟数据（MOCK），仅用于交互与视觉演示，用于验证产品结构，不构成任何投资建议。切换时间周期时数值同步变化，但并非真实市场数据。

真实接入后须注意：① ETF 净流入是「份额变化×净值」的估算值，与交易所披露口径存在差异；② 两融数据存在 T+1 披露延迟，页面须标注「截至上一交易日」；③ 龙虎榜在 16:30-18:00 期间常只发布部分条目，须标注样本条数与取数时点；④ 涨跌家数与资金流向存在多口径并存（含/不含北交所），差异须并列说明。
