二、真实数据的接入方式（已实现）

直连优先：页面底部加载器直接请求东方财富 push2 / push2his / datacenter-web 三个域名（均已实测开放 CORS），在浏览器内组装成与内置 DATA 相同的结构后调用 SMF.update() 渲染，图表配置零改动；交易时段每 60 秒、非交易时段每 300 秒自动刷新。

快照先行：页面打开时先展示浏览器本地留存的上次数据（没有留存时读同仓库的 data.json 快照）立即渲染，不再空白等待直连；随后直连东方财富刷新为实时数据，直连失败就停在已有数据上并自动重试，旧快照不会覆盖更新的数据。快照由 GitHub Actions 运行 scripts/fetch_snapshot.py 在交易时段每 10 分钟生成，口径与前端直连完全一致。顶栏「刷新最新数据」按钮可随时手动直连刷新一次。

状态可见：顶部徽标实时标注当前数据状态（实时数据 / 快照数据 / 模拟数据），两融与龙虎榜的截至日期写在各周期 stamp 里，不会把 T+1 数据冒充实时。

三、信号判定逻辑（页面内自动计算，非人工标注）

  • 高位派发预警 大单净流入 > 0 且 |涨跌幅| < 0.6% 且 量比 ≥ 1.8 —— 巨量滞涨，通常是承接盘在替出货方接单。
  • 主力吸筹 大单净流入 > 0 且 涨跌幅 < 2% —— 资金进场但股价未透支。
  • 主升共振 大单净流入 > 0 且 涨跌幅 ≥ 2% —— 资金与价格同向，趋势最强但需防高位。
  • 拆单暗吸 / 量价背离 大单净流出 < 0 且 涨跌幅 > 0 —— 明面大单流出、股价抗跌，多为算法拆单隐蔽吸筹。
  • 资金撤离 大单净流出 < 0 且 涨跌幅 ≤ 0 —— 价量资金三杀，最弱结构。

四、看盘口诀

  • ETF 是慢钱：连续 3 日净申购而指数横盘＝机构低位收集；单日脉冲多为期现套利，不构成方向。
  • 融资是快钱：融资净买入放大而指数不涨＝杠杆滞涨，是兑现信号而非进攻信号。
  • 板块看连续性：单日资金回正不算信号，连续 2 日净流入且金额递增才有效。
  • 背离看方向：跌不动＋大单流出＝吸筹；涨不动＋巨量大单流入＝派发。
  • 龙虎榜看结构不看个股：机构买、散户卖＝筹码集中；游资接力、机构撤退＝情绪尾声。
  • 四维共振才加仓：ETF 申购＋融资回升＋板块资金转正＋情绪 ≥ 60，缺一即降杠杆。

五、口径与免责

本页数据来自东方财富公开接口：板块与 ETF 主力资金、两市成交额为盘中实时；融资融券为 T+1 披露（截至上一交易日）；龙虎榜为最近交易日席位聚合。不构成任何投资建议。若顶部徽标显示「加载失败」，说明实时与快照均不可用，页面将保持空白并自动重试——本页不使用任何模拟数据。

口径注意：① ETF「净流入」为二级市场主力净额，不是份额申赎，两者方向可能不一致；② 两融数据 T+1 披露，stamp 已标注截至日期；③ 龙虎榜在 16:30-18:00 期间常只发布部分条目，本页取最近交易日全量聚合；④ 成交额为沪市＋深市合计，不含北交所；⑤ 盘中成交额涨跌幅与昨日同时段累计比较，收盘后自动切换为与昨日全天比较。
